# Image and structure check fixtures

Regenerate from the repository root with:

```sh
python tester/fixtures/pdf_checks/generate.py
python -m pytest test_pdf_checks.py
```

The generator uses fixed ReportLab metadata and deterministic pikepdf IDs. Tests
compare generated bytes with these committed PDFs, and independently assert the
expected findings below. Each PDF is one page; relevant page findings locate page 1.
These are focused detector examples, not fully accessible document templates.

| PDF | Expected issue types |
|---|---|
| `tagged_image.pdf` | none: Figure with a nonempty Alt, linked via page MCID |
| `missing_alt.pdf` | `missing_figure_alt` |
| `blank_alt.pdf` | `missing_figure_alt` (whitespace-only Alt) |
| `untagged_image.pdf` | `image_without_text_alternative` |
| `artifact_image.pdf` | none: image drawn inside Artifact marked content |
| `nested_form.pdf` | none: image tagged inside a Form XObject, linked through an MCR with Stm |
| `inline_image.pdf` | `image_without_text_alternative` |
| `missing_structure.pdf` | `missing_document_structure` (document location) |
| `empty_structure.pdf` | `missing_document_structure` (document location) |
| `table_headers.pdf` | none: table has TH and TD cells |
| `table_no_headers.pdf` | `table_missing_headers` |
| `combined.pdf` | `missing_figure_alt`, `table_missing_headers` |

All findings have `classification: human_review`, `status: needs_human_review`,
no repair, and unchanged output bytes. Missing structure/Figure Alt has
`evaluation_result: fail`; uncertain image associations/table headers have
`evaluation_result: needs_review`. An empty findings array only describes the
limited checks performed, never certifies conformance.

The automated suite also constructs custom roles, inherited pages, repeated image
uses, unused resources, inline artifacts, nested tables, malformed/cyclic structures
and forms, and mixed human-review/automatic-repair cases in memory.

Detection follows the W3C techniques [PDF1](https://www.w3.org/WAI/WCAG21/Techniques/pdf/PDF1),
[PDF4](https://www.w3.org/WAI/WCAG21/Techniques/pdf/PDF4), and
[PDF6](https://www.w3.org/WAI/WCAG21/Techniques/pdf/PDF6).
